Entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf?ref=lycann666) bounty **Funniest Forecast for a City That Isn't** — one line, at most 120 characters, the funniest weather forecast for a city that does not exist.

The entry writes a single line to `/output/entry.txt`:

> Cloudy in Mistport today, with fog so thick the lighthouse has asked for directions.

84 characters. Mistport is an invented foggy harbour town, and its lighthouse — the one thing whose job is to see through fog — has itself asked for directions.

## Run

```sh
python3 main.py
```

The program writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` when set, otherwise to `/output`.
